# Signaler une faille de sécurité

Merci de signaler toute vulnérabilité **de façon confidentielle**, avant de la rendre publique, par le formulaire de contact d'Andryale : https://andryale.org/contact/

Ne publiez pas de ticket public pour une faille. Indiquez si possible la version concernée, les étapes pour reproduire et l'impact supposé.

L'adresse de signalement est aussi publiée dans `https://exu.fr/.well-known/security.txt` (RFC 9116).

## Versions suivies

Le projet est en préversion (0.x.1). Seule la dernière version publiée est suivie. Aucun scrutin réel n'est organisé sur exu.fr pour le moment.
